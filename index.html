01
Redresseur · المُقوِّم
AC → DC · Diodes · Pont de Graëtz
Convertisseur alternatif-continu
📋
Aperçu général
3 min
▼

Le redresseur transforme la tension AC du réseau en tension DC. Le Pont de Graëtz (4 diodes) exploite les deux alternances pour une meilleure efficacité. Un condensateur réduit l'ondulation (ripple). Applications : alimentations pour moteurs DC, chargeurs de batteries.

Convertisseur AC → DC
4 diodes 1N4007 en pont
Double alternance exploitée
Condensateur C réduit le ripple
Simple alt. : 1 diode seulement
Applications : MCC, batteries
Formules
Simple alt.
Vo = Emax / π ≈ 0.318·Emax
Double alt. pont
Vo = 2·Emax / π ≈ 0.637·Emax
Triphasé étoile
Vo = 0.827·Emax
Triphasé pont
Vo = 1.65·Emax
Veff
Veff = Emax / √2 ≈ 0.707·Emax
Ripple ondulation
fo = 2f (mono) / 6f (pont 3φ)
Exemple examen
📝 Redresseur triphasé pont
Réseau 220V/50Hz. Charge Rc = 10Ω. Calculez Vo, Io, Id, fo.
Emax = 220×√2 = 311 V Vo = 1.65×311 = 513 V Io = 513/10 = 51.3 A | Id = 17.1 A | fo = 300 Hz
⚠️ Déconnecter avant modification. Décharger C (Q=CU). Isolation 220V obligatoire.
02
Redresseur Commandé · المُقوِّم المُتحكَّم
Thyristor SCR · Angle α · AC → DC variable
Commutation contrôlée
📋
Aperçu général
3 min
▼

Le redresseur commandé remplace les diodes par des thyristors SCR. L'amorçage se fait par impulsion sur la gâchette (Gate) quand VAK>0. L'angle α retarde l'amorçage et contrôle Vdc. Blocage uniquement par annulation naturelle (IAK→0). Applications : variateurs vitesse MCC.

Thyristor SCR

04
Hacheur (Chopper) · القاطع
DC → DC · MOSFET/IGBT · PWM · Rapport cyclique α
Convertisseur continu-continu
📋
Aperçu général
3 min
▼

Le hacheur convertit DC → DC. Un MOSFET commute à haute fréquence selon un signal PWM. Rapport cyclique α = ton/T. Buck : Vs=α·Ve. Boost : Vs=Ve/(1−α). Applications : variateurs MCC, MPPT solaire.

05
Onduleur Autonome · العاكس
DC → AC · Pont H · IGBT · Dead Time · Filtre LC
Convertisseur continu-alternatif
📋
Aperçu général
3 min
▼

L'onduleur autonome convertit DC → AC. Un pont H de 4 IGBT commute : S1+S4 → +Vdc, S2+S3 → −Vdc. Résultat : onde carrée 50Hz. Filtre LC → sinusoïde. Dead Time empêche le court-circuit. Applications : UPS, ALTIVAR, PV.
